What is Floeval?
Floeval supports five evaluation types: LLM, RAG, Prompt, Agent (single), and Agentic Workflow (multi-agent DAG). Each maps to a different dataset shape and set of metrics.
📄
LLM evaluation
Direct question-answer quality without retrieval. Use answer_relevancy. Dataset: user_input + llm_response.
🔍
RAG evaluation
Answer quality and retrieval performance. Use faithfulness, context_precision, context_recall. Dataset includes contexts.
📝
Prompt evaluation
Compare one or many system-prompt variants at scale. Define prompts in a file; dataset uses prompt_ids. Works with or without RAG.
🤖
Agent evaluation
Single agent trace scoring: goal achievement, coherence, and tool call accuracy. Dataset: AgentDataset with full or partial samples.
🔗
Agentic workflow
Multi-agent DAG pipelines. Define a DAG with nodes and edges; each AGENT node is scored independently. Uses WorkflowRunner.
🛠️
Two ways to use
Flow 1: CLI — Run from config + dataset files.
Flow 2: Python — Integrate directly into your app.

Flow 1: Using CLI
Run evaluations from the command line. No Python code needed.

CLI command

Standard (LLM/RAG/Prompt) flow:

Command 
floeval evaluate -c CONFIG_FILE -d DATASET_FILE [-o OUTPUT_FILE]

Agent flow:

Command 
floeval evaluate --agent -c CONFIG_FILE -d DATASET_FILE [-o OUTPUT_FILE]
OptionRequiredDescription
--agentNoUse Agent or Agentic Workflow evaluation flow. Omit for standard LLM/RAG/Prompt evaluation.
-c, --configYesPath to config file (YAML or JSON)
-d, --datasetYesPath to dataset file (JSON or JSONL)
-o, --outputNoSave results to JSON file. If omitted, prints to terminal.

Standard flow: Full vs Partial dataset

TypeDescriptionWhen to use
Full datasetEach sample has llm_response. Evaluation runs directly.You already have LLM answers (e.g. from your app).
Partial datasetSamples have only user_input (question). llm_response is omitted. Floeval generates it at runtime, then evaluates.You have questions but no answers yet. Floeval calls your LLM to generate responses internally.

Partial dataset flow: For each sample, Floeval sends user_input as the prompt to your LLM (with optional system_prompt from config). The LLM returns a response, which is stored as llm_response. Then metrics (answer_relevancy, faithfulness, etc.) run on that generated response. Config must include dataset_generation_config.generator_model for partial datasets.

Capability: For partial datasets, only user_input is required. contexts, ground_truth are optional (add them if you need faithfulness or reference comparison).

Agent flow: Agent dataset format

Agent datasets use JSON with a samples array. Each sample has user_input and either a full trace or a partial (no trace).

TypeDescriptionWhen to use
Full (trace present)Each sample has user_input, trace, optionally reference_outcome, reference_tool_calls. Evaluation runs directly.Pre-captured traces — you already have the conversation logs.
Partial (no trace)Samples have user_input, reference_outcome, optionally reference_tool_calls. Trace omitted. Config must include evaluation_config.agent_name for FloTorch hosted agents.Run agent at evaluation time (in-process or FloTorch hosted).

Agent config: For agent flow, config requires evaluation_config.metrics (no default). For partial agent datasets, set evaluation_config.agent_name to use FloTorch gateway agent.

Step-by-step

  1. Create config.yaml — See config structure below.
  2. Create dataset.json — Full (with llm_response) or Partial (questions only). See examples below.
  3. Run: floeval evaluate -c config.yaml -d dataset.json
  4. Optional: Add -o results.json to save results.

Config file (YAML)

config.yaml 
llm_config:
  base_url: "https://api.openai.com/v1"
  api_key: "your-api-key"
  chat_model: gpt-4o-mini
  embedding_model: text-embedding-3-small
  system_prompt: "You are a helpful assistant."  # optional

evaluation_config:
  default_provider: "ragas"   # optional; see Config field notes below
  metrics:
    - ragas:answer_relevancy
    - ragas:faithfulness
  metric_params:
    answer_relevancy:
      threshold: 0.7

# Omit for full datasets. Required only for partial datasets (no llm_response).
dataset_generation_config:
  generator_model: gpt-4o-mini

Config field notes:
default_provider — optional. Used when metrics are plain strings (e.g. answer_relevancy) and the metric exists in multiple providers. If omitted: auto-picks when only one provider has it; if ambiguous, use ragas:answer_relevancy or set default_provider.
metric_params — optional. Override per-metric parameters.
dataset_generation_config — omit for full datasets; required for partial.

config.json — alternative format 
{
  "llm_config": {
    "base_url": "https://api.openai.com/v1",
    "api_key": "your-api-key",
    "chat_model": "gpt-4o-mini",
    "embedding_model": "text-embedding-3-small",
    "system_prompt": "You are a helpful assistant."
  },
  "evaluation_config": {
    "default_provider": "ragas",
    "metrics": ["ragas:answer_relevancy", "ragas:faithfulness"],
    "metric_params": {
      "answer_relevancy": {"threshold": 0.7}
    }
  },
  "dataset_generation_config": {
    "generator_model": "gpt-4o-mini"
  }
}

Dataset file (JSON)

LLM/RAG/Prompt sample fields: user_input (or question) — always required. llm_response — required for full datasets; omit for partial (Floeval generates it). contexts — optional; needed for faithfulness. ground_truth (or answer) — optional; used by reference metrics.

full_dataset.json — full (has llm_response)

Agent dataset file (JSON)

How to prepare agent datasets

Full dataset — you have conversation logs. Export each run as a sample with user_input + trace. Partial dataset — you have test cases (user_input + expected outcome). Omit trace; Floeval runs your agent at eval time and captures the trace.

Where do traces come from? (1) Your app — log messages as they happen. (2) LangChain — wrap_langchain_agent captures automatically. (3) Custom agents — use @capture_trace + log_turn/log_tool_result.

reference_tool_calls format: use "name" not "tool". Example: [{"name": "get_weather", "args": {"city": "Tokyo"}}]

Full dataset — trace is the conversation log. Each message has role (human|ai|tool), content. AI messages include tool_calls with name and args. Tool messages include tool_name, tool_call_id.

agent_dataset_full.json — full (complete trace example) 
{
  "samples": [
    {
      "user_input": "Get the weather for London",
      "trace": {
        "messages": [
          {"role": "human", "content": "Get the weather for London"},
          {"role": "ai", "content": "", "tool_calls": [{"name": "get_weather", "args": {"city": "London"}}]},
          {"role": "tool", "content": "Sunny, 22°C", "tool_name": "get_weather", "tool_call_id": "call_1"},
          {"role": "ai", "content": "The weather in London is sunny with 22°C.", "tool_calls": []}
        ],
        "final_response": "The weather in London is sunny with 22°C.",
        "metadata": {}
      },
      "reference_outcome": "Provides London weather",
      "reference_tool_calls": [{"name": "get_weather", "args": {"city": "London"}}]
    }
  ]
}

Partial dataset — omit trace. Agent runs at evaluation time (in-process or FloTorch hosted):

agent_dataset_partial.json — partial (no trace) 
{
  "samples": [
    {
      "user_input": "Get the weather for London",
      "reference_outcome": "Provides London weather",
      "reference_tool_calls": [{"name": "get_weather", "args": {"city": "London"}}]
    }
  ]
}

Agentic Workflow config (YAML)

Use agent_workflow_config with a DAG config. Requires pip install "floeval[flotorch]".

YAML config 
llm_config:
  base_url: "https://gateway.example/openai/v1"
  api_key: "your-gateway-key"
  chat_model: "gpt-4o-mini"

evaluation_config:
  metrics:
    - "goal_achievement"
    - "ragas:agent_goal_accuracy"

agent_workflow_config:
  dataset_url: "https://your-storage/agent_dataset.json"
  config:
    uid: "workflow-001"
    name: "Triage Workflow"
    nodes:
      - {id: "start",    type: "START", label: "Start"}
      - {id: "classify", type: "AGENT", label: "Classify", agentName: "classifier-agent:latest"}
      - {id: "respond",  type: "AGENT", label: "Respond",  agentName: "responder-agent:latest"}
      - {id: "end",      type: "END",   label: "End"}
    edges:
      - {sourceNodeId: "start",    targetNodeId: "classify"}
      - {sourceNodeId: "classify", targetNodeId: "respond"}
      - {sourceNodeId: "respond",  targetNodeId: "end"}
Bash 
floeval evaluate -c workflow_config.yaml -d agent_dataset.json --agent -o workflow_results.json

Full vs Partial dataset (Python)

Same as CLI: Full = samples have llm_response. Partial = only user_input; Floeval generates llm_response at runtime by calling your LLM with each user_input. Use partial_dataset=True and pass dataset_generator_model.

Basic Python example — Full dataset

Python — samples already have llm_response 
from floeval import Evaluation, DatasetLoader
from floeval.config.schemas.io.llm import OpenAIProviderConfig

LLM_CONFIG = {
    "base_url": "https://api.openai.com/v1",
    "api_key": "your-api-key",
    "chat_model": "gpt-4o-mini",
    "embedding_model": "text-embedding-3-small",
}
llm_config = OpenAIProviderConfig(**LLM_CONFIG)

dataset = DatasetLoader.from_samples([
    {"user_input": "What is Python?", "llm_response": "Python is a programming language."},
    {"user_input": "What is RAG?", "llm_response": "RAG stands for Retrieval-Augmented Generation."}
], partial_dataset=False)

evaluation = Evaluation(
    dataset=dataset,
    llm_config=llm_config,
    metrics=["answer_relevancy"],
    default_provider="ragas"
)

results = evaluation.run()
print(results.aggregate_scores)

Basic Python example — Partial dataset

Python — no llm_response; Floeval generates at runtime 
# Partial: only user_input required. contexts, ground_truth optional
partial_ds = DatasetLoader.from_samples([
    {"user_input": "What is Python?", "contexts": ["Python is widely used."]},
    {"user_input": "What is RAG?", "contexts": ["RAG combines retrieval with generation."]}
], partial_dataset=True)

evaluation = Evaluation(
    dataset=partial_ds,
    llm_config=llm_config,
    metrics=["answer_relevancy", "faithfulness"],
    default_provider="ragas",
    dataset_generator_model="gpt-4o-mini",  # required for partial
)

results = evaluation.run()
# Internally: for each sample, Floeval sends user_input to LLM,
# gets llm_response, then runs metrics on it
print(results.aggregate_scores)

Agent: In-process with LangChain (Tier 1 — auto capture)

wrap_langchain_agent(agent) captures traces automatically. Requires langchain, langchain-openai. Create partial.jsonl first — save in same folder as script. JSONL = one JSON object per line; partial = no trace:

Create partial.jsonl — one JSON object per line 
{"user_input": "What is 15 * 7 + 3?", "reference_outcome": "Uses calculator, returns 108", "reference_tool_calls": [{"name": "calculator", "args": {"expression": "15 * 7 + 3"}}]}
{"user_input": "What's the weather in Paris?", "reference_outcome": "Uses get_weather", "reference_tool_calls": [{"name": "get_weather", "args": {"city": "Paris"}}]}
Python — LangChain agent + tools, auto trace capture 
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.tools import tool

from floeval.api.agent_evaluation import AgentEvaluation
from floeval.config.schemas.io.agent_dataset import AgentDataset
from floeval.config.schemas.io.llm import OpenAIProviderConfig
from floeval.utils.agent_trace import wrap_langchain_agent

@tool
def calculator(expression: str) -> str:
    """Evaluate a mathematical expression."""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"Error: {e}"

@tool
def get_weather(city: str) -> str:
    """Get weather for a city."""
    db = {"paris": "18°C", "tokyo": "22°C", "london": "14°C"}
    return db.get(city.lower(), f"{city}: No data")

llm = ChatOpenAI(model="gpt-4o-mini", api_key="your-key", base_url="https://api.openai.com/v1")
agent = create_agent(model=llm, tools=[calculator, get_weather], system_prompt="Use tools when needed.")
llm_config = OpenAIProviderConfig(base_url="https://api.openai.com/v1", api_key="your-key", chat_model="gpt-4o-mini")

dataset = AgentDataset.from_file("partial.jsonl")  # create this file first (see above)
evaluation = AgentEvaluation(
    dataset=dataset,
    metrics=["goal_achievement", "response_coherence", "ragas:tool_call_accuracy"],
    llm_config=llm_config,
    agent=wrap_langchain_agent(agent),
)
results = evaluation.run()
print(results.summary["aggregate_scores"])

Python — custom agent with manual trace logging 
from floeval.api.agent_evaluation import AgentEvaluation
from floeval.config.schemas.io.agent_dataset import AgentDataset, ToolCall
from floeval.config.schemas.io.llm import OpenAIProviderConfig
from floeval.utils.agent_trace import capture_trace, log_turn, log_tool_result

llm_config = OpenAIProviderConfig(base_url="https://api.openai.com/v1", api_key="your-key", chat_model="gpt-4o-mini")

@capture_trace
def my_agent(user_input: str) -> str:
    search_result = f"Mock search for: {user_input}"
    log_tool_result("search", search_result)
    final = f"Answer based on: {search_result}"
    log_turn(output=final, tool_calls=[ToolCall(name="search", args={"query": user_input})])
    return final

partial_ds = AgentDataset.from_file("agent_partial.json")  # create this file first (see above)
evaluation = AgentEvaluation(
    dataset=partial_ds,
    llm_config=llm_config,
    agent=my_agent,
    metrics=["goal_achievement"],
    default_provider="builtin",
)
results = evaluation.run()

Dict with params[{"id": "answer_relevancy", "provider": "ragas", "params": {"threshold": 0.8}}]
Metric instance[my_custom_metric, "answer_relevancy"]

When using plain strings: set default_provider if the metric exists in multiple providers (e.g. answer_relevancy in ragas and deepeval). Use provider:metric to avoid ambiguity without setting default_provider.

#!/usr/bin/env python3
"""Custom metric with question + contexts. NO API KEY!"""
from floeval import Evaluation, DatasetLoader
from floeval.api.metrics.custom import custom_metric

@custom_metric(threshold=0.4)
def context_relevance(response: str, question: str, contexts: list) -> float:
    if not response or not question:
        return 0.0
    q_words = set(question.lower().split())
    r_words = set(response.lower().split())
    q_match = len(q_words & r_words) / max(len(q_words), 1)
    ctx_usage = 0.0
    if contexts:
        ctx_text = " ".join(contexts).lower()
        ctx_words = set(ctx_text.split())
        ctx_usage = min(len(ctx_words & r_words) / max(len(r_words), 1) * 2, 1.0)
    return min(q_match * 0.6 + ctx_usage * 0.4, 1.0)

dataset = DatasetLoader.from_samples([
    {
        "user_input": "What is RAG?",
        "llm_response": "RAG stands for Retrieval-Augmented Generation.",
        "contexts": ["RAG combines retrieval with generation."]
    },
    {
        "user_input": "How does ML work?",
        "llm_response": "Machine learning uses algorithms.",
        "contexts": ["RAG stands for Retrieval-Augmented Generation."]
    }
])

evaluation = Evaluation(dataset=dataset, metrics=["context_relevance"])
results = evaluation.run()
print("\n📊 Scores:", results.aggregate_scores)
print("✅ Done! (No API key)")

#!/usr/bin/env python3
"""Agent: in-process agent with @capture_trace. Dry run (PassMetric, no API)."""
from floeval.api.agent_evaluation import AgentEvaluation
from floeval.api.metrics.base import BaseMetric, MetricResult
from floeval.config.schemas.io.agent_dataset import AgentDataset, PartialAgentSample, ToolCall
from floeval.utils.agent_trace import capture_trace, log_turn, log_tool_result

class PassMetric(BaseMetric):
    """Dummy metric for dry run — always passes, no API needed."""
    def __init__(self):
        super().__init__(name="pass")
    def evaluate(self, sample, **kwargs):
        return MetricResult(score=1.0, metadata={})

@capture_trace
def mock_agent(user_input: str) -> str:
    log_tool_result("search", f"Mock result for: {user_input}")
    final = f"Answer: {user_input}"
    log_turn(output=final, tool_calls=[ToolCall(name="search", args={"q": user_input})])
    return final

# Partial dataset (no trace — agent will run)
dataset = AgentDataset(samples=[
    PartialAgentSample(user_input="What is Python?", reference_outcome="Explains Python"),
])

evaluation = AgentEvaluation(
    dataset=dataset,
    metrics=[PassMetric()],
    agent=mock_agent,
)
results = evaluation.run()
print("Sample results:", results.sample_results)
print("✅ Done! (No API key)")

#!/usr/bin/env python3
"""Agent: LangChain agent with tools. Partial dataset — agent runs at eval time."""
import os
from pathlib import Path
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.tools import tool
from floeval.api.agent_evaluation import AgentEvaluation
from floeval.config.schemas.io.agent_dataset import AgentDataset
from floeval.config.schemas.io.llm import OpenAIProviderConfig
from floeval.utils.agent_trace import wrap_langchain_agent

@tool
def calculator(expression: str) -> str:
    """Evaluate a mathematical expression."""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"Error: {e}"

@tool
def get_weather(city: str) -> str:
    """Get weather for a city."""
    db = {"paris": "18°C", "tokyo": "22°C", "london": "14°C"}
    return db.get(city.lower(), f"{city}: No data")

llm_config = OpenAIProviderConfig(
    base_url=os.getenv("OPENAI_BASE_URL", "https://api.openai.com/v1"),
    api_key=os.getenv("OPENAI_API_KEY", "your-api-key"),
    chat_model=os.getenv("OPENAI_CHAT_MODEL", "gpt-4o-mini"),
)
llm = ChatOpenAI(
    model=llm_config.chat_model,
    api_key=llm_config.api_key,
    base_url=llm_config.base_url,
)
agent = create_agent(
    model=llm,
    tools=[calculator, get_weather],
    system_prompt="Use tools when needed. Answer accurately.",
)

DATA_FILE = Path(__file__).resolve().parent / "agent_partial.jsonl"
dataset = AgentDataset.from_file(DATA_FILE)
evaluation = AgentEvaluation(
    dataset=dataset,
    metrics=["goal_achievement", "response_coherence", "ragas:tool_call_accuracy"],
    llm_config=llm_config,
    agent=wrap_langchain_agent(agent),
)
results = evaluation.run()
print("Summary:", results.summary)
